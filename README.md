# Road Accident Analysis
Interactive Power BI dashboard analyzing road accident data to identify accident patterns, severity trends, and high-risk factors using data visualization and KPI reporting.

## Objective
To analyze road accident data and identify patterns related to accident frequency, severity, location, vehicle types, and environmental conditions.

## Key KPIs Tracked
- Total Casualties: 195.7K
- Total Accidents: 144.4K
- Fatal Casualties: 2.9K
- Serious Casualties: 27.0K
- Slight Casualties: 165.8K

##Dashboard Features
- Accident trend analysis comparing current year vs previous year
- Casualty distribution by vehicle type (car, bike, bus, van, etc.)
- Accident severity analysis (fatal, serious, slight)
- Road type analysis to identify high-risk road categories
- Urban vs rural accident comparison
- Accident distribution based on lighting conditions
- Geographic accident visualization using map integration
- Weather and road surface filtering for deeper analysis

## Key Insights Generated
- Majority of accidents involved cars
- Most accidents occurred on single carriageway roads
- Urban areas had higher accident rates than rural areas
- Majority of accidents occurred during daytime
- Identified high-risk locations and accident patterns
